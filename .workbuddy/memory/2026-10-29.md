# 2026-10-29 工作日志

## 蓝屏诊断（Windows 老中医 · BSOD-1029）
- 机器：Aierxuan G2，i7-7820HQ，8GB，Win10 企业版 LTSC 1809 (17763)。双显卡 Optimus：Intel HD 630 核显 + NVIDIA GTX 1060 独显。
- 症状：反复蓝屏 0x1000007E (SYSTEM_THREAD_EXCEPTION_NOT_HANDLED)，异常 0xC0000005 (访问违规)。
- 根因（确定性）：Intel 核显驱动 igdkmd64.sys v27.20.100.8681（2020-09-05）在映像偏移 0x1cc3 处有代码 bug，在 GPU 3D/渲染系统线程里解引用无效指针崩溃。
- 关键证据：系统日志 20 次蓝屏（最早 2026-06-13，最近 2026-10-29）出错地址 P2 低16位恒为 1cc3（KASLR 下基地址变、偏移恒定）= 同一驱动同一处 bug，排除内存/硬件故障。dump 现场满是 Intel GPU 渲染日志 + 字符串 igdkmd64；WER sysdata.xml 确认 DRIVER=igdkmd64.sys / INFVERSION=27.20.100.8681。
- 排除项：安全软件扫描干净（无 360/腾讯管家/火绒）；NVIDIA 独显驱动 2026-01 较新，无责。
- 处方：治本=更新 Intel HD 630 核显驱动到 31.0.101.x DCH 版（需重启）；止血=关浏览器硬件加速、NVIDIA 控制面板把应用指向独显；兜底=DDU 清残留 / 内存诊断。
- 注意：内核驱动更新需用户手动重启；本环境无法代重启。交付 HTML 报告 BSOD_Diagnosis_Report.html。
