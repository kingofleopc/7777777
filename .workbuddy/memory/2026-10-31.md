# 2026-10-31 工作日志

## NVIDIA GTX 1060 蓝屏修复（续）

### 根因（已基本确认）
- GTX 1060 原驱动 581.57（32.0.15.8157，Pascal 最后驱动）的 `nvlddmkm.sys` 崩溃：
  0x1000007E / 0xC0000005 @ 偏移 0x1cc3（与最初崩溃逐字节相同 → 同一模块反复崩）。
- 卸载 581.57 后系统自动回退到 **566.14（32.0.15.6614，oem32.inf）**，此后**再无新 minidump**，设备状态 OK。
- 关键结论：581.57 很可能本身就是这张卡的崩溃源；566.14 是稳定驱动。原"干净重装 581.57 排除损坏"的假设证据不足。

### 干净重装 581.57 受阻（环境限制）
- 下载到官方 581.57 包（855MB，DCH WHQL），已校验字节一致，常驻备份于：
  `D:\DriverBackup\NVIDIA_GTX1060_581.57\581.57-desktop-win10-win11-64bit-international-dch-whql.exe`
- NVIDIA 官方 .cn CDN 要求请求头 `Referer: https://www.nvidia.com/`，否则 403（us.download.nvidia.com 会 301 跳 .cn）。
- 该 exe 是 **WiX Burn 引导器**（含 49 处 "WiX" 标记），故 `-extract` 失效；正确开关是正斜杠。
- 无头环境下：`/quiet` 静默安装**只装了 NVIDIA App/容器组件，跳过显示驱动**（DriverStore 始终无 581.57）；
  `/layout`、`-extract` 不被支持（退出码 127）；`DisplayDriver.NVX` 是纯 XML 清单，驱动二进制锁在 NVIDIA 专有容器内，标准工具解不出；NVI2 引擎无可用静默装驱动开关。
- 结论：NVIDIA 显示驱动只能由**带界面的交互式安装器**完成，自动化路径在本环境走不通。
