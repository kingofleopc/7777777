生成时间：2026-10-29 20:08 · 机器：Aierxuan G2（i7-7820HQ / 8GB / Win10 企业版 LTSC 1809）· 就诊编号 #BSOD-1029

① 结论先行（老中医望闻问切）

根因确定 严重度：中高 推荐：更新核显驱动

蓝屏代码 0x1000007E SYSTEM_THREAD_EXCEPTION_NOT_HANDLED，异常 0xC0000005 访问违规。 崩溃发生在 Intel HD Graphics 630 核显内核驱动 igdkmd64.sys（版本 27.20.100.8681，2020-09 发布） 的一个确定性代码缺陷上——出错指令恒位于该驱动映像偏移 0x1cc3。 这不是内存条坏道，也不是硬件损坏，而是驱动太老 + 旧代码 bug。

该崩溃已反复发生至少 20 次，最早追溯到 2026-06-13，约每几天一次，严重影响正常工作。治本方案：把 Intel 核显驱动换成新版本。

④ 根因分析

双显卡笔记本（Optimus）：内屏与日常加速由 Intel HD 630 核显承担，独显 GTX 1060 负责重负载。Intel 核显驱动停留在 2020 年的 27.20.100.8681，其某一渲染/提交代码路径（偏移 0x1cc3）在特定条件下对一个无效指针解引用，抛出 0xC0000005，运行在系统线程中即触发 0x7E 蓝屏。 近期 Edge/WebView2（10-28）、金考典（10-22）、QQ（10-17）等会加大核显负载，使崩溃更频繁——但根因始终是那个旧驱动，与这些软件无关。

⑤ 分层处置路线（开方）

首选 · 治本 更新 Intel 核显驱动

  • 把 igdkmd64.sys 27.20.100.8681（2020） 换成 Intel 官方 7~10 代核显驱动 31.0.101.2145（Legacy 分支最新，明确支持 Windows 10 1809/RS5，HD 630 在支持列表内）。
  • 获取方式（任选）：① 官方下载页 intel.com/download/776137（搜索 "Intel 7th-10th Gen Processor Graphics"），下 gfx_win_101.2145.exe（约 278MB）；② 安装 Intel 驱动与支持助手 (DSA) 自动匹配；③ Windows Update 的"可选更新"里检查显卡驱动。
  • 安装方式：双击运行安装包，或用设备管理器 → 显示适配器 → Intel HD Graphics 630 → 更新驱动 → 自动/浏览。
  • ⚠️ 内核驱动更新必须重启才能生效（新驱动在下次开机加载）。

立刻止血 更新驱动前先降低核显负载

  • 浏览器（Edge / Chrome）关闭"使用硬件加速"：设置 → 系统 → 关闭"使用硬件加速（如果可用）"，重启浏览器。
  • 在 NVIDIA 控制面板 → 管理 3D 设置 → 全局/程序设置 中，将常用软件首选图形处理器设为"高性能 NVIDIA 处理器"，让独显接管、绕开核显 bug 路径。
  • 暂停运行会压核显的软件（硬件加速的视频/图形/考试软件）直到驱动更新完成。

兜底 若换新驱动后仍崩溃

  • 用 DDU（Display Driver Uninstaller） 进安全模式彻底清除 Intel 驱动残留，再装干净版。
  • 跑一次 Windows 内存诊断（搜索"Windows 内存诊断"）排除内存问题——但偏移恒定已基本排除 RAM 故障。
  • 若独显可完全接管显示（如长期外接显示器），可在 BIOS/UEFI 将显卡模式设为"独显直连(Discrete)"，但会失去内屏输出，不推荐作为首选。
⚠️ 风险提示：内核显卡驱动更新属中高风险操作——若新驱动与 LTSC 1809 不兼容，少数情况下可能开机黑屏。请先备份重要文件，并确保手边能进"安全模式"（开机按 F8/Shift+重启）以便回滚。更新前我会先备份当前驱动信息，但重启需你本人操作（本环境无法代你重启）。

⑥ 需要你亲自操作的步骤（GUI / 重启类）

1
联网下载 HD 630 最新 DCH 驱动（或装 Intel DSA 自动获取），建议先存到本地。
2
运行安装包完成驱动替换（过程中可能闪屏，属正常）。
3
重启电脑，让新内核驱动生效；重启后观察几天是否还有 0x1000007E。
4
若重启后黑屏：进安全模式 → 设备管理器回滚/卸载 Intel 显卡驱动，系统会退回基础显示驱动。
